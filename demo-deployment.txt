### 💻 Want to Try This Yourself? Follow These Steps:

**1. Create a Kubernetes cluster** on Google Cloud.

**2. Create a working directory:**
`mkdir kubernetes-demo`

**3. Navigate into it:**
`cd kubernetes-demo`

**4. Clone the repository:**
`git clone https://github.com/GoogleCloudPlatform/microservices-demo.git`

**5. Navigate to the release directory:**
`cd microservices-demo/release`

**6. Deploy the application:**
`kubectl apply -f kubernetes-manifests.yaml`

**7. Verify your deployment:**
- `kubectl get pods`
- `kubectl get deployments`
- `kubectl get services`

**8. Access the application:**

Copy the External IP of the Frontend Service and open it in your browser.

That's it! You've successfully deployed a microservices-based application on Kubernetes. 🎯
