

docker trouble shoot and monitoring commands

1. docker inspect
Purpose: To get detailed information about a Docker container, image, network, or volume.

It returns information in JSON format.

docker inspect container_name

It provides information such as:
- Container ID and name.
- Container status (running, stopped, exited).
- Image used to create the container.
- IP address.
- Port mappings.
- Volume mounts.
- Environment variables.
- Container configuration.
- Resource limits.


2. docker top
Purpose: To display the processes currently running inside a Docker container.
docker top container_name 
Field	Meaning
UID	  User running the process
PID	    Process ID
PPID	Parent process ID
C	    CPU utilization indicator
STIME	Process start time
TTY	    Terminal associated with process
TIME	CPU time consumed
CMD	     Command/process name
Important: docker top displays processes; it does not provide a live interactive process monitor.

3. docker logs
Purpose: To view logs generated by an application running inside a container.

docker logs container_name



4. docker stats
Purpose: To monitor resource utilization of running Docker containers.
It displays live statistics for all running containers.

This command is similar to monitoring CPU and memory usage on a Linux machine.

docker stats
Column	Meaning
CONTAINER ID	Container identifier
NAME	Container name
CPU %	CPU utilization
MEM USAGE	Current memory consumption
MEM LIMIT	Maximum memory available to container
MEM %	Memory utilization percentage
NET I/O	Network data received/transmitted
BLOCK I/O	Disk data read/written
PIDS	Number of processes

5. What is htop?
htop is an interactive Linux process monitoring tool.

It helps you monitor the overall resource utilization of your Linux machine.

Think of it as an advanced version of the Linux top command.

It displays:

CPU utilization.

Memory utilization.

Swap utilization.

Running processes.

Process IDs (PID).

CPU and memory consumption per process.

Load average.

System uptime.

How to install htop in Ubuntu
sudo apt update
sudo apt install htop -y

How to execute it
htop

docker system df:-Check how much disk space Docker is consuming.
It displays disk usage by:
- Images
- Containers
- Local volumes
- Build cache



docker system prune:- Remove unused Docker resources to free up disk space.
By default, it removes:
- Stopped containers.
- Unused networks.
- Dangling images (untagged images not referenced by containers).
- Unused build cache.




docker image prune -a 
Purpose: Remove all unused Docker images, not just dangling images.
It removes images that are not referenced by any existing container, whether running or stopped.
