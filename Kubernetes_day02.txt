  #Q. what is blue-green in kubernetes..?
  Blue-Green Deployment in Kubernetes is a deployment strategy where we maintain two identical environments 
  (Blue and Green) and switch user traffic from the old version to the new version after confirming that the new version is working correctly.
The main purpose is to achieve zero or minimal downtime and easy rollback during application updates.
  Blue-Green = Deploy separately, test separately, switch traffic, and roll back easily.
  
  # what is canary deployment?
  Canary Deployment in Kubernetes is a deployment strategy in which we release 
  a new application version to a small percentage of users first, monitor its performance, 
  and gradually increase traffic if everything works correctly.

  ##Q. what are kuernetes 4 services
  "Kubernetes provides four Service types: ClusterIP, NodePort, LoadBalancer and ExternalName. 
  These services provide different ways to expose applications and enable communication inside or outside the Kubernetes cluster.
  kube-proxy implements Service networking for the first three in typical kube-proxy-based clusters, while ExternalName works through DNS.
  
  Service type	Explanation	Example
1. ClusterIP	Exposes an application internally within the cluster.	Backend communication
2. NodePort	Exposes an application through a port on every node's IP address.	Access application using NodeIP:Port
3. LoadBalancer	Exposes an application externally using a cloud provider's load balancer.	Public application access
4. ExternalName	Maps a Kubernetes Service to an external DNS name.	Access an external database using a Kubernetes service name
